# 排版細則

SKILL.md「排版」一節的補充。每條都帶例子。

## 數字

**千分位**：五位及以上的數字加半形逗號；四位數可加可不加。

```
公司的實收資本為 NT$1,258,000。
```

**單位**：數字和英文單位之間加空格。

```
16 GB 記憶體
1 h = 60 min = 3,600 s
```

**貨幣**：數字前寫貨幣符號，或數字後寫中文名稱。

```
$1,000
1,000 美元
```

**百分號**：半形 `%`，緊跟數字，不加空格：`6.5%`。

**範圍**：用 `～` 或「至」連接，兩端都帶單位。

```
132 kg～234 kg
67%～89%
2009 年～2011 年
-20 °C 至 -10 °C
```

**增減**：「了」表示變化量，「到」表示結果。

```
增加到兩倍：原來 1，現在 2
增加了兩倍：原來 1，現在 3
降低到 80%：原來 100，現在 80
降低了 80%：原來 100，現在 20
```

減少只用百分比，不說「降低 N 倍」。

## 標點

**句號**：句末括號註解放在句號前面。

```
差：請參照第 1.3 節（見第 26 頁。）
好：請參照第 1.3 節（見第 26 頁）。
```

**括號**：補充說明用全形 `（）`，前後不加空格。

```
請確認所有連接（電纜和接頭）均已安裝牢固。
```

**冒號**：解釋說明用全形 `：`；時間用半形 `:`，如 `8:00`。

**逗號**：一段話裡不能一逗到底。一個意思說完就用句號。

**分號**：只用在並列的分句之間。

**驚嘆號**：不用。不能連用 `！！`。

**破折號**：寫成 `——`（佔兩個漢字寬）。盡量改用逗號、冒號或括號。

**連接號**：
- 兩個名詞複合、圖表編號，用半形 `-`：`氧化-還原反應`、`圖 1-1`。
- 數值範圍用 `～`，見上文「範圍」。

**行首**：句號、逗號、頓號、分號、冒號、問號、驚嘆號不出現在行首。

## 英文

**縮寫**：第一次出現時，在括號裡給出全稱和中文，之後直接用縮寫。

```
IOC（International Olympic Committee，國際奧林匹克委員會）
```

**大小寫**：專有名詞每個詞首字母大寫，普通名詞小寫。產品和技術名稱按官方寫法：`GitHub`、`JavaScript`、`macOS`。

**複數**：英文複數譯成中文時還原成單數：`RAMs` → `RAM`。

**書名、文章名**：英文裡的引號，在中文裡改成書名號。書名用 `《》`，文章名用 `〈〉`：`〈航空業的未來〉`。
